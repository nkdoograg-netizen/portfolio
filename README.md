# Nitin Kumar Doogra — Portfolio

A single-file, responsive developer portfolio built with HTML, CSS and JavaScript.

- **Live site:** https://nkdoograg-netizen.github.io/portfolio/
- **Resume PDF:** [Nitin-Kumar-Doogra-Resume.pdf](Nitin-Kumar-Doogra-Resume.pdf)

## Features

- Bold, colorful responsive design with animated gradients
- Photo changer (upload / reset / save a portable copy)
- Projects pulled from GitHub with live demo links
- "Download My Details (PDF)" via the browser print dialog, plus a direct PDF file
- Copy-to-clipboard email button
- Contact links: email, GitHub and LinkedIn

## Files

- `index.html` — the entire website (photos and styles embedded)
- `Nitin-Kumar-Doogra-Resume.pdf` — ready-to-download resume
- `Photograph.jpeg` — original profile photo

## Local preview

Open `index.html` in any browser, or serve the folder:

```bash
python -m http.server 8000
```
